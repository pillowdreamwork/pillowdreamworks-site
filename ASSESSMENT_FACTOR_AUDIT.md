# Assessment Factor Audit

## Scope and method

This audit covers the 161 free assessments currently loaded by `js/assessments-data.js` (177 catalog entries total, including 16 paid entries). A result is classified as multi-factor only when the current scoring implementation returns separate factor values or the existing item grouping and documented construct unambiguously support separate scores. Descriptions of multiple topics alone are not treated as subscales. Existing overall sums and scoring thresholds are unchanged.
