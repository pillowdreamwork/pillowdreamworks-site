Privacy Policy

Last updated: 20 September 2026

This Privacy Policy explains the personal information we may collect through PillowDreamWorks Foundation’s website and services, why it is collected, how it is used, and how it is handled.

This site is a static website and currently does not use a server-side database or an automated CRM. At the moment, personal data is not automatically stored in a database by the code on this site. Information is processed in the browser and may be transmitted to third-party services or email/WhatsApp channels when a visitor links to or uses them.

1. Information we may collect

The site may collect or request the following information from visitors when they use the forms or contact functions:

  • Name
  • Email address
  • Phone / WhatsApp number
  • Service interest or purpose of inquiry
  • Message text and preferred time/date for a session
  • Age, gender, and assessment-related intake details on the free assessment intake form
  • Order preference and pricing selections for digital or session products
  • Uploaded handwriting sample file names and file sizes when a user chooses a handwriting sample in the graphotherapy section

2. Why we collect this information

We collect this information to:

  • Respond to service inquiries
  • Schedule counselling, crisis support, or graphotherapy sessions
  • Deliver digital product or workbook information
  • Process order and booking requests shown on the site
  • Provide assessment-related support and follow-up
  • Contact a user about their requirement or booking

3. How information is used

Information may be used to communicate with the visitor, coordinate a session or order, confirm a booking, respond to a question, or provide follow-up information relevant to the chosen service. The site may also use some information locally in the browser during a session, such as intake details shown in the self-assessment experience.

4. Where it is stored or processed

At the time of this review, the website code does not include a backend server, database, payment processor, analytics platform, or customer-tracking database. The site primarily runs as static HTML, CSS, and JavaScript files in the browser. In practice:

  • Some data may remain only in the browser session while the page is in use.
  • Checkout and form flows currently redirect to local pages and display the entered information in the page URL or locally in browser memory.
  • External websites are contacted when a user clicks YouTube, WhatsApp, Fiverr, LinkedIn, Instagram, or email links.
  • Third-party content delivery networks may receive standard request metadata such as IP address and user-agent when a page loads.

5. Third-party services and processors

The site currently loads third-party resources from the following services:

  • Tailwind CSS CDN
  • Lucide icon CDN
  • Google Fonts
  • YouTube
  • WhatsApp
  • Fiverr
  • LinkedIn
  • Instagram

These services have their own terms and privacy policies. The site does not currently include a verified Lemon Squeezy integration, a ParityDeals integration, or an affiliate tracking script in the codebase reviewed.

6. Payment processing

The site code reviewed does not include a working payment gateway, checkout API, or live payment processor. The current book and toolkit pages use front-end-only flows that route to confirmation screens rather than processing live card payments. If a payment processor is introduced later, that processor will become a separate data controller/processor and the site’s practices must be updated to reflect it.

7. Analytics and tracking

The website code reviewed does not include Google Analytics, Meta Pixel, Hotjar, Mixpanel, Segment, or similar tracking scripts. No cookies, localStorage, or sessionStorage usage were identified in the static site code reviewed. However, external resources may still receive regular HTTP metadata when the page is loaded.

8. Contact and assessment information

Contact forms, booking forms, and assessment intake forms collect only the fields needed to respond to a request or begin an assessment. The site does not currently provide a backend dashboard or auto-export tool for captured form data. If you submit a form, the interaction may be handled by the browser and by the email/WhatsApp channel linked from the site, depending on how the business operates.

9. User rights and requests

Because the current site does not store personal data in a central server-side system, there is not a verified automated deletion or correction workflow in the code reviewed. If you need to request information or ask for a correction, please write to the contact address below. If the business later implements a backend or data storage system, that system will need a specific deletion and retention process.

10. Retention

No verified retention period is currently implemented in the code reviewed for site data. The site does not have a confirmed server-side data retention policy in place.

11. Contact

For privacy questions, data requests, or concerns, contact: support@pillowdreamworks.com

12. Updates

This policy may be updated when the website’s functionality changes, such as when a new backend, payment processor, data processor, or analytics tool is introduced. Please review this page periodically.

This notice is intended for informational purposes and is not a substitute for legal advice. If you are operating a counselling, assessment, or ecommerce site in a jurisdiction with specific privacy obligations, please confirm local requirements with a qualified legal professional.
